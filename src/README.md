# Pipeline

Run in this order. Each script's docstring explains what it does, what broke in
earlier versions, and why it is built the way it is — those notes are the point,
not decoration.

| # | script | does | needs a GPU |
|---|---|---|---|
| 1 | `extract_activations.py` | builds the corpus: oasst1 + LMSYS prompts, responses generated by Gemma itself; extracts activations from inside the assistant response | yes |
| 2 | `roundtrip.py` | AV → explanation → AR → reconstruction, SAE on both ends. Saves all four vector families, per-example FVE **and** MSE for four comparisons, and the source text | yes |
| 3 | `refeature.py` | re-encodes the saved vectors under a different SAE. Seconds | no |
| 4 | `label_features.py` | auto-interp with held-out scoring and a wrong-label null | yes |
| 5 | `judge_explanations.py` | per feature: does the explanation cover it? `CLEARLY`/`PROBABLY`/`UNCLEAR`/`NO`, against two nulls | yes |
| 6 | `describe_buckets.py` | English summaries of shared/lost/made from the labels **alone**, blind to the explanation, with controls | yes |
| 7 | `classify_features.py` | grammar/content × generic/specific × actually-in-the-text, with a control on a different document | yes |
| — | `trust_report.py` | **the tool.** Per-activation trust report; labels unseen features on demand | yes |
| — | `matcher_bakeoff.py` | diagnostic: compares judge prompts on identical pairs. How the stage-5 prompt was chosen | yes |

## Vendored, and why

`nla_av.py` and `sampling.py` are copied in rather than imported, because this
fork modified them:

- **`nla_av.py`** carries the **Gemma embed-scale fix**. `get_input_embeddings()`
  returns the embedding *module*; calling it runs
  `Gemma3TextScaledWordEmbedding.forward()`, which **already** multiplies by
  `√hidden_size`. Multiplying again made every token embedding 62× too large and
  produced repetition loops even with no injection. Invisible on Qwen, whose
  scale is 1.0.

  It began as the AV wrapper for a separate `<thinking>`-scratchpad experiment
  that stays in the previous repo. All of that was removed here — 438 → 199
  lines — and the result verified by re-running the same seed and diffing:
  identical FVE to four decimals and identical feature counts on all five
  activations.
- **`sampling.py`** holds `load_vectors`, the seeded row sampler. Hand-rolled
  selection was tried twice and was wrong both times: rows `0..n` gave several
  positions of a **single document**, and first-row-per-document
  systematically picked the **earliest, least-context** position in each —
  measured at FVE 0.64 against 0.76 for properly sampled rows.

`nla_inference.py` and the `nla/` package come from the upstream repo
(`kitft/natural_language_autoencoders`). Set `NLA_REPO` to a clone, or place this
repo inside one.

## Conventions every script follows

- **Nothing is reported without its null.** Any rate that could be produced by a
  broken measurement is computed twice — once on real data, once on mismatched
  data — and both are printed.
- **The numbers contain no model judgement.** Counts, feature sets and overlaps
  are vector arithmetic and integer set operations. Where a language model is
  used, its output is labelled as generated.
- **Selection is logged, not hidden.** The FVE gate picks activations on the
  outcome metric; every seed tried is recorded.
- **Coverage is stated.** ~50% of features have a validated label. The rest are
  counted in every total and never named.
