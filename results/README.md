# Results

Everything `scripts/run_experiment.sh` produces. Regenerate the whole directory
with that one command.

## Start here

| file | |
|---|---|
| **`SUMMARY.md`** | **every number quoted in [RESULTS.md](../RESULTS.md)**, as tables, starting with the headline table in section 0 |
| `summary.json` | the same, machine-readable |
| `example_reports/` | six single activations followed end to end — the aggregates spot-checked against individual cases |
| `per_example.csv` | one row per (activation, explanation, variant): FVE *and* cosine for all four comparisons, latent counts, Jaccard and its control, token counts, CJK/untagged flags |
| `LATENTS_BY_BUCKET.md` | all 200 activations: the AV's explanation, the source text, every labelled latent grouped shared / lost / made. Nothing inferred — the labels are simply listed |

Generated by `src/summarize_results.py` and `src/example_reports.py` from the
raw artefacts below. **Quote from `SUMMARY.md`, not from a hand-computed
figure** — that is how four errors reached an earlier write-up.

## Raw artefacts

| file | |
|---|---|
| `feature_overlap.json` | the round trip: 600 records (200 activations x 3 paragraph variants) with the AV's explanation, the source text, per-example MSE / FVE / cosine for all four comparisons, latent sets, per-latent strengths, and the near-miss distance sweep |
| `feature_overlap_l0_small.json` | latent sets re-encoded at L0~21 — used wherever a latent must be *named* |
| `feature_overlap_l0_big.json` | latent sets re-encoded at L0~120 — used for the reconstruction claim |
| `feature_labels.json` | 3,329 labels, each with its **AUC** and the **wrong-label null scores** it was validated against. `reliable: true` means it beat the 95th percentile of that null; 1,771 did |
| `grounding.json` | per (latent, explanation, variant): the grade, the verdict, **both null rates**, the label's AUC, and the latent's categories |
| `explanation_splits.json` | the paragraph split's success rate, plus 20 splits dumped verbatim so the cut point can be eyeballed |

## Not in the repo

`feature_overlap_vectors.npz` (25 MB) holds all four vector families —
`v_orig`, `v_orig_sae`, `v_ar`, `v_ar_sae` — plus the near-miss neighbour
activations. The corpus parquet (7.8 MB) holds the activations and source text.
Both are excluded by `.gitignore` as binary artefacts;
`scripts/run_experiment.sh` regenerates them.

The `.npz` is what [FUTURE_WORK.md](../FUTURE_WORK.md) needs: `v_orig_sae` lets
the SAE's own reconstruction error be subtracted out, so an effect can be
attributed to the AR rather than confounded with SAE lossiness.
