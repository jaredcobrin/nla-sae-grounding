# Results

Everything `scripts/run_experiment.sh` produces. Regenerate the whole directory
with that one command.

## Start here

| file | |
|---|---|
| **`SUMMARY.md`** | **every number quoted in [RESULTS.md](../RESULTS.md)**, as tables |
| `summary.json` | the same, machine-readable |
| `per_example.csv` | one row per (activation, explanation): FVE *and* cosine for all four comparisons, latent counts, Jaccard and its control, CJK/untagged flags |
| `LATENTS_BY_BUCKET.md` | per activation: the AV's explanation, the source text, and every labelled latent grouped shared / lost / made. Nothing inferred — the labels are simply listed |

Those four are generated by `src/summarize_results.py` from the raw artefacts
below. **Quote from `SUMMARY.md`, not from a hand-computed figure** — that is how
four errors reached an earlier write-up.

## Raw artefacts

| file | |
|---|---|
| `feature_overlap.json` | the round trip: 250 runs with the AV's explanation, the source text, per-example MSE / FVE / cosine for all four comparisons, latent sets, and per-latent activation strengths |
| `feature_overlap_l0_small.json` | latent sets re-encoded at L0≈21 — used wherever a latent must be *named* |
| `feature_overlap_l0_big.json` | latent sets re-encoded at L0≈120 — used for the reconstruction claim |
| `feature_labels.json` | 1,624 labels, each with its **AUC** and the **wrong-label null scores** it was validated against. `reliable: true` means it beat the 95th percentile of that null |
| `grounding.json` | per (latent, explanation): the grade, the verdict, **both null rates**, the label's AUC, and the latent's categories |

## Not in the repo

`feature_overlap_vectors.npz` (6.5 MB) holds all four vector families —
`v_orig`, `v_orig_sae`, `v_ar`, `v_ar_sae` — and the corpus parquet (3 MB) holds
the activations and source text. Both are excluded by `.gitignore` as binary
artefacts; `scripts/run_experiment.sh` regenerates them.

The `.npz` is what [FUTURE_WORK.md](../FUTURE_WORK.md) needs: `v_orig_sae` lets
the SAE's own reconstruction error be subtracted out, so an effect can be
attributed to the AR rather than confounded with SAE lossiness.
